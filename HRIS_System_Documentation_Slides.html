Section 1

Executive Summary

Documents the system as it exists today — modules, features, end-to-end flows, and how modules depend on each other.

  • 15 functional modules across Core Records, Self-Service, Workflow & Approvals, Configuration, and Reporting
  • 6-role authorization model: ADMIN, HR, EMPLOYEE, SUPERVISOR, COUNCIL, VICEMAYOR
  • Multi-stage Leave decision workflow spanning Employee, HR, Supervisor, Council Secretary and Vice-Mayor accounts
  • Built continuously through Change Requests CR-015 → CR-023, not a single rewrite
This is a documentation exercise — no application code was changed to produce it.

Section 5

Feature Summary — Core Records

  • Employee Records: the 201-file master, credentials/role provisioning
  • PDS: 10 sub-sections, employee self-edit with server-side ownership checks, "N/A" print for blanks
  • Appointments / Service Record: HR-maintained history + document attachments
  • 201 Files: general document repository by Document Type
  • Archive (CR-023): SALN / Resigned / Leaves folders, now admin-manageable — add/rename/delete via Manage Folders, delete blocked while files exist
HRIS Manila Council5 · Feature Summary — Core Records
Section 6

Feature Summary — Workflow & Approvals

  • Leave Management: CS Form 6 filing → multi-actor decision flow → Leave Card posting; appeal/cancel; monthly accrual; Leave Tracker calendar; CS Form 6 / Leave Card / Verification Receipt PDFs
  • Clearance: employee files, each configured approver signs off, approved/disapproved PDF
  • Training & Seminar: per-employee training records with certificate upload, feeds PDS Learning & Development

Section 7

Feature Summary — Self-Service, Config & Reporting

  • Notifications: session-scoped bell, unread badge
  • Dashboard/Nav: role-based landing pages, quick-nav badges
  • Auth & Roles: BCrypt (legacy auto-migrate), 6 roles, self-service password change
  • System Settings: ~22 lookup CRUD screens (Departments, Salary Grades, Leave Types, Holidays, …)
  • Reports: Jasper PDFs across every module
  • Year-End Processing: mandatory-leave deduction, scheduled + on-demand
