# Impeccable Design Context — HRISP (Manila City Council HRIS)

## Design Context

### Users
HR/administrative officers of the Manila City Council (Secretariat, HRM Section) processing
records for ~430 employees on desktop office PCs during working hours; employees occasionally
view their own records read-only. Data-entry heavy, repetitive clerical work: filing CS Form 6
leave applications, maintaining the employee leave-card ledger, printing official PDFs.

### Brand Personality
Civic, precise, dependable. The software equivalent of a well-kept municipal records office:
calm, orderly, nothing decorative that doesn't serve the record. Owner's stated direction:
"modern, simple, user-friendly, impeccable."

### Aesthetic Direction
- Light theme (daytime office clerical context).
- OWNER DECISION (2026-07-12): stay strictly inside the existing Limitless/Bootstrap 4 admin
  theme. No custom fonts, no custom scoped design systems, no novel button styles — a page
  that looks different from the rest of the system confuses the clerical users and external
  font/CSS fallbacks fail on office machines. "Better" means cleaner use of the theme's own
  components (cards, card-headers, btn-primary/bg-teal/bg-indigo, badges, DataTables), not a
  new visual language.
- Anti-references: generic admin-dashboard "hero metric" cards, colored side-stripe borders,
  glassmorphism, dark neon, and any one-off page-local design system.

### Constraints
- Pages live inside the existing Limitless/Bootstrap 4 + jQuery + DataTables admin shell.
  Enhancements are scoped (`.leave-module` wrapper CSS) — the global sidebar/navbar/footer and
  other modules must remain untouched.
- Server-rendered Thymeleaf; no build step; CSS lives in the template or a static css file.
- Thymeleaf 3.0.11: `lt/gt/le/ge/eq/ne/and/or/not` are reserved — never use as th:each vars.

### Design Principles
1. The record is the interface — tables read like well-typeset ledgers (tabular figures,
   right-aligned numbers, hairline rules), not like generic admin grids.
2. One primary action per surface; everything else is secondary or quiet.
3. Status is communicated with type + small color chips, never with loud fills or stripes.
4. Vary spacing for rhythm: tight within groups, generous between sections.
5. Nothing moves unless it communicates state; motion is entrance/feedback only, ease-out.
